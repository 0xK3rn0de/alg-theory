# Clothing Calculator (Вариант 7)

Приложение для расчёта расхода ткани и стоимости пошива одежды: пиджак, брюки, костюм-тройка.

## Описание
Программа позволяет выбрать тип изделия, ввести размер, цену ткани, стоимость фурнитуры и работы. 
Рассчитывает необходимый метраж ткани и итоговую стоимость. 
Результат можно сохранить в отчёт формата .docx.
